# Names and branding

The Apache 2.0 license covers m-dash's code and documentation. It does not grant
rights to names or logos ([section 6](LICENSE)). This page explains what is
welcome, so forks and packagers don't have to guess.

**Welcome without asking:**
- Forking, modifying and redistributing m-dash under its licenses.
- Saying that your project is "based on m-dash" or "a fork of m-dash".
- Packaging unmodified official releases for a package manager, as long as the
  package description links back to this repository.
- Using the CND artwork and CND Hybrid Display font inside m-dash or a modified
  m-dash, as [BRAND-LICENSE.txt](BRAND-LICENSE.txt) allows.

**Please don't:**
- Distribute a modified build under the name "m-dash" in a way that suggests it is
  an official release. Use a distinct name, or clearly mark it as unofficial.
- Use the CND artwork or font as the branding of an unrelated product.
- Imply endorsement by Chuck Dudley, CND, or any AI provider.

OpenAI, Codex, Anthropic, Claude, xAI, Grok and OpenRouter are trademarks of their
respective owners. m-dash uses those names only to identify compatible services
and is not affiliated with or endorsed by them.
